How a review runs

        [..............................]   0%
      

      

        
01
Read the diff
Every changed line, plus the 200 lines around it. Generated files and lockfiles are skipped, renames are followed.
reading src/api/upload.ts
  +12 −1  (3 hunks)
skipping package-lock.json

        
02
Pull in context
Orbit finds the callers, the tests that cover this code, and the last six months of commits that touched it.
callers      4 files
tests        upload.spec.ts (11)
history      7 commits, 2 reverts

        
03
Review with your rules
Checks correctness, security and performance first. Style only if you ask — your linter already has opinions.
rules  .orbit.yml
  - flag: unvalidated user input
  - ignore: naming, formatting
  - max_comments: 5

        
04
Prove it before posting
Every suggestion is applied in a sandbox and your test suite runs against it. If tests fail, the comment is never posted.
sandbox  apply 3 suggestions
tests    214 passed, 0 failed
post     3 comments  ✓
