MODERN DATA STACK LAB

Trải nghiệm Hạ tầng Dữ liệu Chuẩn Doanh Nghiệp

Mỗi học viên được cấp tài khoản truy cập cụm máy chủ Cloud Data Warehouse riêng, làm việc với dữ liệu bẩn (dirty data), tự xử lý missing values và tối ưu câu lệnh SQL chạy dưới 1 giây.

▸ Database: PostgreSQL, Google BigQuery, Snowflake
▸ Pipeline: Python, Pandas, Polars, dbt, Apache Airflow
▸ BI & AI: Power BI (DAX), Streamlit, OpenAI/LangChain
STAGE 01 // ADVANCED SQL & DATA MODELING

Truy vấn SQL Chuyên sâu & Thiết kế Kho Dữ liệu Star Schema

Thành thạo CTEs, Window Functions, tối ưu Index/Partitioning và xây dựng mô hình dữ liệu Dimensional Modeling (Fact & Dimension Tables) phục vụ báo cáo đa chiều.

STAGE 02 // BI STORYTELLING & METRICS TREE

Thiết kế Power BI Dashboard Tự động & Phân tích Chỉ số Kinh doanh

Xây dựng cây chỉ số (North Star Metric, Cohort, RFM, Unit Economics), viết hàm DAX phức tạp và kể chuyện bằng dữ liệu (Data Storytelling) giúp Ban Giám đốc ra quyết định.

STAGE 03 // PYTHON AUTOMATION & MACHINE LEARNING

Làm sạch Dữ liệu bằng Python, Thống kê Kiểm định A/B Testing

Tự động hóa quy trình thu thập và xử lý dữ liệu bằng Pandas, kiểm định giả thuyết A/B Testing và huấn luyện mô hình Phân cụm khách hàng, Dự báo doanh thu (XGBoost/Scikit-learn).

STAGE 04 // DATA PIPELINE & ENTERPRISE RAG AI

Đường ống ETL Tự động & Trợ lý AI Truy vấn Dữ liệu Nội bộ

Đóng gói đường ống dữ liệu với Docker, lập lịch chạy tự động trên Airflow/dbt và tích hợp mô hình ngôn ngữ lớn (Text-to-SQL & RAG) để hỏi đáp trực tiếp trên dữ liệu doanh nghiệp.
